# Médias pour posts OPTIMAT

Place des images ici pour qu'elles soient parfois jointes aux posts :

```
media/ready/
  photo1.jpg
  chart.png
```

Formats : `.jpg` `.jpeg` `.png` `.webp` `.gif`  
Taille conseillée : < 900 Ko.

OPTIMAT choisit une image au hasard dans `ready/` quand il poste.

Tu peux aussi commit des visuels trouvés / générés (libre de droits) dans ce dossier.
